# Sales Analytics Project

## Project Overview
This project analyzes sales data using PostgreSQL. It helps identify revenue trends, customer spending patterns, and product performance.

## Database Tables
- **Customers:** Stores customer names, cities, and signup dates.
- **Products:** Stores product names, categories, and prices.
- **Orders:** Stores order details, quantities, and order dates.

## Tools Used
- PostgreSQL
- pgAdmin 4
- Visual Studio Code

## SQL Concepts Used
- SELECT, WHERE, ORDER BY, LIMIT
- Aggregate functions: SUM, COUNT, AVG
- GROUP BY and HAVING
- JOIN operations
- Subqueries
- Views
